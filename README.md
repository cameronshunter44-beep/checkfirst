# CheckFirst

CheckFirst helps people understand the real cost of major financial decisions before they commit.

## Included checks
- Car purchase
- Home buying
- Solar financing
- Personal loans
- Big purchase financing
- Rent
- Job offer comparison

## Features
- Quick Check and Full Check modes
- Live calculations
- Responsive customer-facing interface
- Local saved checks
- Saved-check comparison entry point
- Printable/exportable reports
- No API keys required for the core app

## Run
```bash
npm install
npm run dev
```

## Deploy
Designed for Next.js deployment on Vercel.
